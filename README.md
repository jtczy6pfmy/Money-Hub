# Money Hub

Shared household finance app built with Supabase.

## Foundation
- Responsive dashboard for Windows, iPad and phone
- Supabase Auth sign-in/sign-up
- Shared household initialization
- Dashboard, Accounts, Bills, Income, Debt, Savings
- Spending, Paycheck Planner, Reports, Reminders and Settings
- Financial Logins foundation with encrypted-vault architecture
- Existing mechanic tables are not modified
